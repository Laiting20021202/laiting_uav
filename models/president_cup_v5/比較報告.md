# president_cup_v5 微調與比較結果

唯一初始模型為 `competition_5class_v1-3/weights/best.pt`（YOLO11m），保留原有五個類別。新模型為 `best.pt`，最後一輪權重另存 `last.pt`。

完成 3 輪環境適應與 17 輪聯合訓練，共 20 輪。最終 best.pt 依聯合訓練驗證 mAP50–95 選擇，來自聯合訓練第 17 輪。

## 固定門檻的物件辨識比較

以下使用同一組 120 張保留測試圖，1536 輸入、信心門檻 0.25、NMS IoU 0.6。每個預測框按類別與 IoU≥0.5 進行一對一匹配。誤判比例定義為 FP／(TP+FP)，漏檢數是未匹配的標註目標。這裡的 precision／recall 為合計物件數的比例，與 Ultralytics 五類平均數不同。

| 指標 | 原始 1-3 | president_cup_v5 |
|---|---:|---:|
| 正確框 TP | 414 | 435 |
| 誤判框 FP | 63 | 48 |
| 漏檢目標 FN | 74 | 53 |
| Precision | 86.79% | 90.06% |
| Recall | 84.84% | 89.14% |
| 誤判比例 | 13.21% | 9.94% |

同一測試集 mAP50：76.37% → 97.11%；mAP50–95：65.17% → 76.14%。mAP 使用 conf=0.001 的完整信心曲線。

## 訓練資料與設定

訓練 2,377 張、驗證 135 張、測試 120 張。包含原有五類參考圖、55–140 公尺高度的模擬影像、平坦光／軟陰影／強陰影、826 張軍用結構裁切、450 張保持標註幾何的退化增強，以及原始參考圖的重複取樣。

背景訓練新增／保留 300 張地形負樣本、150 張城市背景負樣本、63 張目視確認不含目標的室內裁切。新增 48 個實驗室正樣本訓練項目，源自三個人工標註影格的原圖、退化版本、脈絡裁切，以及一份重複取樣權重。

訓練維持 YOLO11m，凍結前 6 個 backbone 模組；AdamW、低學習率（第一階段 0.00015，第二階段 0.0001）、1536 尺寸。旋轉、縮放、透視、翻轉與亮度增強見兩份 training_config。全部資料通過標註檢查，train／val／test 間完全相同的影像雜湊重疊為 0。

## 輸出與使用

- `best.pt`：選定的 v5 權重。
- `last.pt`：最後完成一輪的權重。
- `video_validation/comparison_side_by_side.mp4`：左 v5、右原始 1-3。
- `video_validation/president_cup_v5.mp4`：v5 完整標註影片。
- `video_validation/*.csv`：各模型的逐筆框、類別、信心與時間戳。
- `evaluation/`：全部對照數據與來源紀錄。
- `dataset_manifest.json`、`lab_positive_annotations.json`：資料與人工標註來源。

```python
from ultralytics import YOLO
model = YOLO("models/president_cup_v5/best.pt")

```
